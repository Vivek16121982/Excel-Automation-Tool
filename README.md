📊 Excel Sales Report Automation Tool
🚀 Overview
This project automates sales reporting using Python, Pandas, OpenPyXL, and Matplotlib.

The tool reads sales data from Excel, performs analysis, generates charts, and creates an interactive Excel dashboard automatically.

✨ Features
Read Excel Data
Calculate Total Sales
Department-wise Sales Analysis
Identify Top Employee
Generate Automated Excel Reports
Create Dashboard with KPIs
Generate Bar Charts
Generate Pie Charts
🛠 Technologies Used
Python
Pandas
OpenPyXL
Matplotlib
